# 东京冬日旅行手册

静态旅行网页，直接打开 index.html 或启用 GitHub Pages。

行程为原计划摘要，班次、价格、营业待出行前确认。不含预订号、PIN 或账户。打卡只保存在浏览器。

本地预览：`python3 -m http.server 8765`。

## 详细版（2026-11-01）

- guide.js：五日详解、16个摄影建议、官方来源与核验范围。
- enhance.js：摄影筛选、小红书搜索入口、关键词复制和来源页。
- 搜索入口不是具体笔记推荐；搜索无法读取时，不编造笔记链接。
- 摄影站位与时间分配为编辑建议，未实地踩点。
- 不上传用户打卡，不新增个人资料。
- 只更新GitHub Pages版本，原Sites版本保留。

## 顶部路线地图（2026-11-01）

- route-map.js：独立SVG概略路线图，全程／市区切换，按天高亮和行程跳转。
- 不调用地图瓦片、定位、路由或付费API；点地名才打开Google地点搜索。
- 线条不是实际行车轨迹，地理位置概略、两个视图不同尺度；不用于导航。
- 设计参考：TREK（https://github.com/liketrek/TREK，15281 Star）和TRIP（https://github.com/itskovacs/trip，1957 Star），数值于2026-11-01经GitHub API核对。未复制代码或截图。
- 原始页面修改前备份在项目根目录outputs/tokyo-map-before-update。

## 手册修订（2026-11-01）

仍是同一本静态手册：日轨、六个页签、拍照机位、来源、清单和预算都留着。这一版把已经核对过的约束写进正文，没有新造营业钟点或票价。

- 硬约束：正餐不排拉面；1/2 河口湖必去，只有大雪封路或停运才改市区；箱根按浪漫特快来回；银座放在 12/30 晚上。已读笔记写 1/1 银座商场基本关闭，回城后不另排，当天仍以门口告示为准。12/31 按早关、1/1 按多休来留余量，不补写没核对过的钟点。
- 金额改为人民币在前、日元在括号。汇率沿用 JPY 100 ≈ CNY 4.7，四舍五入到元。合计按日元总额折算，所以和逐行相加可能差 1 元。
- 支付只写常见规律：市内电车用 Suica／Pasmo，官网和晴空塔多走信用卡，小店、老店和券售机常要现金或 IC，寺社备硬币，便利店一般可银联取现。小作的支付仍只引用该店官网，不套到别家。
- 小红书只收已读结论，不放笔记链接：跨年仍以明治神宫为主，增上寺、都厅前、王子狐狸仅为备选；ほうとう补充完熟屋、浅间茶屋（营业待确认）；浅草避开 Ginza Brazil、湘南饭店、Gonpachi 和寺边网红猪排。攻略书签每一天补了一句安排，搜索按钮仍是关键词。
- 航班与酒店只保留班次、酒店名和日期。机票已出。票号、订座编号、确认号和 PIN 不进入公开页。成田 U-City 已取消。浪漫特快、箱根周游券、富士回游或 Busta、晴空塔日期票和 Suica 截至 2026-11-01 仍未购买。
- 官方来源的核对日期仍是 2026-11-01。富士回游、浅草文化观光中心和晴空塔正文此前就没有完整读到，页面上继续标明。
